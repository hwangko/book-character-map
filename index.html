🛠 새 방 만들기

한 번 만든 방은 데이터베이스에 저장돼서 나중에 이어서 할 수 있어요.

1. 방 / 모둠

모둠마다 2×2 크기의 근거지(🏰)가 지도에 자동 배치돼요. 근거지는 빼앗을 수 없어요.

2. 진행 방식 / 문제 / 규칙

땅 1칸 = 객관식 2문제 + 주관식 1문제 모두 정답
아이템은 5연속 정답마다 🛡️방금 차지한 땅 보호 또는 🎁2칸 무료 중 하나가 자동으로 바로 사용돼요. 따라 쓰기는 복사·붙여넣기가 막혀 있어요.

3. 단어 목록 (한 줄에 하나: 영어,뜻 / 뜻이 여러 개면 "/" 로 구분 / 8개 이상)
